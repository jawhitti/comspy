COMSpy Open Source Project

 

Due to popular demand COMSpy is going open source soon, but for now please don't distribute this URL. 

State of the code

The code is somewhat messy right now because I stopped working on it before I got everything done.  Thus, some of the comments are misleading.  This code is not exactly what was used to build the currently distributed version - I was too dumb to use source control and contaminated the code later when I started trying to make MTA spying work (it still doesn't).  However it's pretty close.

To build COMSpy download the code here.  For minimum trouble unzip it into a folder called \projects\comspy.

You will see the following folders and projects:

bin output of other projects goes here.  Should be empty
ctlspysrv Way back when COMSpy was called the "control spy".  This project builds ctlspysrv.dll which is the nucleus of the whole thing.
debugger Creates the AGENT executable (the taskbar icon app).  ctlspysrv.dll and comspy.exe communicate via this process.
hookcfg Creates spycfg.exe - simple ATL Dialog App.
spygui MFC App that implements the GUI.  This code is disgusting, as I was just cut-n-pasted to get stuff up as quickly as possible.  Those of you who want to add GUI features will want to spend time in this project.

To build COMSpy

I don't have a build script so just build the above projects.  After you have built them you will need to nmake ctlspysrv\ctlspysrvps.mk and debugger\debuggerps.dll (obviously these are proxy/stub DLLs).  Once you have built and registered these things you should be able to use COMSpy as usual.
